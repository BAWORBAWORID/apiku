POST /api/ai/chat v2.1 Stable

AI Chat Completion

Stream or synchronously generate conversational completions powered by top-tier open-source and proprietary LLMs with deterministic JSON schemas and zero infrastructure setup.

lock_open Authentication Requirements
FREE VIP ACCESS

All requests must supply your authenticated API key via header or query parameter. VIP keys experience unthrottled streaming speed and zero queue prioritization.

Header: X-API-Key: YOUR_KEY content_copy
Param: ?apikey=YOUR_KEY content_copy

Body Parameters (application/json)

3 schema attributes
Parameter Type Required Description
prompt string required The user message or conversation turn string to be answered by the neural agent.
model string optional Inference backbone. Default: gpt-4o-mini. Also accepts deepseek-r1, gemini-1.5.
system string optional System instructions defining the persona, domain limits, or output formatting constraints.

Implementation Sample

terminal — bash 
curl -X POST "https://api.zyvor.my.id/api/ai/chat" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: zy_live_7x9924a87" \
  -d '{
    "prompt": "Explain quantum entanglement for high-schoolers.",
    "model": "gpt-4o-mini",
    "system": "You are an engaging science educator."
  }'
